# \# Gestión de Tareas Pendientes

# 

# Aplicación de escritorio hecha en \*\*C# con Windows Forms\*\* que permite a los estudiantes organizar su lista de tareas pendientes.

# 

# \## Funcionalidades

# 

# \- Escribir una tarea en el cuadro de texto y agregarla a la lista.

# \- Seleccionar una tarea y eliminarla.

# \- Limpiar toda la lista con confirmación.

# \- Mensajes de aviso cuando falta escribir o seleccionar una tarea.

# 

# \## Controles utilizados

# 

# | Control | Nombre |

# |---|---|

# | TextBox | `txtTarea` |

# | Button | `btnAgregarTarea` |

# | ListBox | `lstTareas` |

# | Button | `btnEliminarTarea` |

# | Button | `btnLimpiarLista` |

# 

# \## Cómo ejecutarlo

# 

# 1\. Clona el repositorio:

# &#x20;  ```

# &#x20;  git clone https://github.com/Alex-090907/GestionTareasPendientes.git

# &#x20;  ```

# 2\. Abre el archivo `GestionTareasPendientes.sln` con Visual Studio.

# 3\. Presiona \*\*F5\*\* para ejecutar.
